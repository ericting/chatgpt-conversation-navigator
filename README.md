# ChatGPT 对话导航

ChatGPT 网页版的 Violentmonkey 用户脚本，用于在长对话中快速查找和定位提问、回答。

- 作者：EricTing
- 当前版本：1.0.0
- 日期：2026-11-08

## 功能

- 自动提取当前 ChatGPT 对话中的用户提问和 AI 回答
- 右侧显示问答缩略导航列表
- 点击“问”或“答”跳转到对应消息开头
- 搜索提问或回答
- 超过 5 轮后自动折叠正文，仅保留问答缩略列表
- 支持一键折叠和展开正文
- 支持收起导航面板和 `Ctrl/Cmd + Shift + L` 快捷键
- 支持 `chatgpt.com` 和 `chat.openai.com`

## 安装

1. 安装 [Violentmonkey](https://violentmonkey.github.io/)。
2. 打开 `chatgpt-conversation-navigator.user.js`，点击安装，或在 Violentmonkey 中新建脚本后粘贴内容。
3. 刷新 ChatGPT 页面。
